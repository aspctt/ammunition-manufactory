## Description

Adds the ammunition manufactory, a powered workbench that makes ammunition at 5x the normal speed.

* **Research** - unlocked with Microelectronics.
* **Building** - 5x2, uses 800 W, short-circuits in the rain if built outdoors, links to tool cabinets and can break down.
* **Cost** - 200 of any metal, 150 steel, 50 gold, 10 components and 4 advanced components.
* **Work** - done by colonists assigned to Smithing.

What it makes depends on your mods:

* **Vanilla** - every mortar shell, including the Biotech and Anomaly ones.
* **Combat Extended** - grenades, plus every ammo type used by at least one weapon or turret in your mod list. Unused calibers stay hidden, just like at Combat Extended's own benches.
* **Yayo's Combat 3** - every ammo type.
* **Reel's Turret Pipeline** - turret ammo.

Combat Extended and Yayo's Combat 3 ammo recipes follow those mods' ammo system setting. Turning it off removes them from the manufactory too.

## Installation

Subscribe on the [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3654656592), or place the ammunition-manufactory folder from the release zip inside your RimWorld `Mods` folder.

**REMOVE ANY OLD VERSIONS BEFORE INSTALLING**.

## Compatibility

No dependencies. Works with any of these when they're installed:

* [Combat Extended](https://steamcommunity.com/sharedfiles/filedetails/?id=2890901044), a release from December 2025 or later
* Yayo's Combat 3
* Reel's Turret Pipeline
* Better Architect Menu, which gets the manufactory in its production category
