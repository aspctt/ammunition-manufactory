# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [1.6.1] - 2026-10-14

### Changed

- New preview image showing RimWorld 1.7 support

## [1.6.0] - 2026-10-14

### Added

- RimWorld 1.7 support

### Changed

- Licensed under GPL 3.0 or later, instead of GPL 3.0 only

## [1.5.0] - 2026-09-17

### Added

- Combat Extended arrows, bolts and sling bullets

### Changed

- With Combat Extended, only ammo used by at least one weapon or turret in your mod list can be made, like at Combat Extended's own benches
- Combat Extended ammo recipes follow its ammo system setting
- Needs a Combat Extended release from December 2025 or later

### Fixed

- Combat Extended base ammo types that can't be used showing up as recipes

## [1.4.0] - 2026-02-10

### Added

- Reel's Turret Pipeline support: turret ammo can be made at the manufactory

## [1.3.0] - 2026-01-28

### Added

- Yayo's Combat 3 support: every ammo type can be made at the manufactory

## [1.2.0] - 2026-01-26

### Added

- Better Architect Menu support: the manufactory goes in its production category

## [1.1.0] - 2026-01-26

### Added

- The mod version in About.xml, for version checking

## [1.0.0] - 2026-01-26

First release.
